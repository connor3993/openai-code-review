FRP 内网穿透客户端使用说明

【启动步骤】
1. 确保你的 Spring Boot 项目已经启动，端口是 8080
2. 双击 "启动.bat" 即可运行
3. 看到 "start proxy success" 就是启动成功
4. 关闭窗口即可停止

【两种访问方式】
方式一：直接访问（带端口）
  http://39.102.79.179:28080/你的接口路径

方式二：通过 Nginx 反代（80端口，推荐微信公众号用）
  http://39.102.79.179/wx/你的接口路径
  注意：/wx/ 前缀会自动去掉，你 Spring 项目里的接口不用加 /wx

【微信公众号配置】
服务器地址(URL)填：http://39.102.79.179/wx/你的回调接口路径
例如：http://39.102.79.179/wx/callback

【修改端口】
如果你的 Spring 项目端口不是 8080，编辑 frpc.ini，修改 local_port 的值
